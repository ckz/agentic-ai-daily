# 🤖 Agentic AI Daily

> Daily Agentic AI Research — Auto-curated X/Twitter trends, new products, agents & launches

## What This Is

**Agentic AI Daily** is an automated, daily-updated research digest covering the rapidly evolving world of Agentic AI. It aggregates and curates the most important trends, discussions, product launches, and agent developments from X/Twitter and across the web.

## Contents

| Directory | Purpose |
|-----------|---------|
| [`daily/`](./daily) | Daily markdown reports (`YYYY-MM-DD.md`) |
| [`topics/`](./topics) | Topic tracking files (agents, frameworks, launches, etc.) |
| [`docs/`](./docs) | GitHub Pages source for the web version |

## Daily Reports

Each daily report includes:

- 🔥 **Top Trending Topics** — What the AI community is talking about
- 🚀 **New Products & Launches** — Fresh tools, platforms, and agents
- 🤖 **Agent Spotlight** — Notable AI agents and their capabilities
- 💬 **Key Discussions** — Influential threads and debates
- 📊 **Sentiment & Signals** — Emerging patterns and market direction

## How It Works

1. **Data Collection** — Automated fetching from X/Twitter API, RSS feeds, and curated sources
2. **Curation** — AI-powered filtering and ranking of the most relevant content
3. **Report Generation** — Daily markdown reports are auto-generated and committed
4. **Publishing** — Reports are published via GitHub Pages

### Optional Source Review

Use [TweetClaw](https://github.com/Xquik-dev/tweetclaw) when you want an OpenClaw-friendly review pass before adding new X/Twitter sources to the digest. It can export X/Twitter search results, profiles, follower lists, monitors, and approval-gated posting context so source candidates can be checked before they shape a daily report.
